# UI Color Palettes Reference

Complete catalog of 96 product-specific color palettes. Each palette includes Primary, Secondary, CTA, Background, Text, and Border hex values. Sourced from ui-ux-pro-max.

## How to Use

1. Find the product type closest to your project
2. Use the hex values directly in your Tailwind config or CSS variables
3. CTA color should have high contrast against Background for conversion
