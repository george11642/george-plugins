# UI Font Pairings Reference

Complete catalog of 57 font pairings with Google Fonts URLs, CSS imports, and Tailwind configs. Sourced from ui-ux-pro-max.

## Font Pairing Principles

- **Serif headings + sans body** = classic elegance
- **Geometric sans headings + humanist sans body** = modern warmth
- **Display fonts** = headlines only, never body text
- **Monospace** = code, data tables, technical content
- **Script fonts** = accents/decorations only, never body text
- Match heading/body font personalities (contrast with harmony)

## Size Scale (Tailwind)

```
text-xs    12px    Captions, fine print
text-sm    14px    Secondary text, labels
text-base  16px    Body text (minimum on mobile)
text-lg    18px    Large body, intro text
text-xl    20px    Small headings
text-2xl   24px    Section headings
text-3xl   30px    Page headings
text-4xl   36px    Hero headings
text-5xl   48px    Display headings
```

## Quick Copy-Paste: Top 5 Most Versatile

### 1. Inter (Swiss Minimal)
```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap');
```
```js
fontFamily: { sans: ['Inter', 'sans-serif'] }
```

### 2. Poppins + Open Sans (Modern Professional)
```css
@import url('https://fonts.googleapis.com/css2?family=Open+Sans:wght@300;400;500;600;700&family=Poppins:wght@400;500;600;700&display=swap');
```
```js
fontFamily: { heading: ['Poppins', 'sans-serif'], body: ['Open Sans', 'sans-serif'] }
```

### 3. Playfair Display + Inter (Classic Elegant)
```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Playfair+Display:wght@400;500;600;700&display=swap');
```
```js
fontFamily: { serif: ['Playfair Display', 'serif'], sans: ['Inter', 'sans-serif'] }
```

### 4. Space Grotesk + DM Sans (Tech Startup)
```css
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;700&family=Space+Grotesk:wght@400;500;600;700&display=swap');
```
```js
fontFamily: { heading: ['Space Grotesk', 'sans-serif'], body: ['DM Sans', 'sans-serif'] }
```

### 5. Plus Jakarta Sans (Friendly SaaS)
```css
@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@300;400;500;600;700&display=swap');
```
```js

```
