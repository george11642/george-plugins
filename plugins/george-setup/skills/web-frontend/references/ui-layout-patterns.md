# UI Layout Patterns Reference

Complete catalog of 30 landing page patterns, 96 product-type recommendations, and 100 UI reasoning rules. Sourced from ui-ux-pro-max.

## Landing Page Patterns (30)

### Conversion-Focused Patterns

#### 1. Hero + Features + CTA
- **Sections**: Hero with headline/image → Value prop → Key features (3-5) → CTA section → Footer
- **CTA**: Hero (sticky) + Bottom
- **Colors**: Hero brand primary or vibrant, Features card bg #FAFAFA, CTA contrasting accent (7:1+ contrast)
- **Effects**: Hero parallax, feature card hover lift, CTA glow on hover
- **Conversion**: Deep CTA placement, contrasting color, sticky navbar CTA

#### 2. Hero + Testimonials + CTA
- **Sections**: Hero → Problem statement → Solution overview → Testimonials carousel → CTA
- **CTA**: Hero (sticky) + Post-testimonials
- **Conversion**: Social proof before CTA, 3-5 testimonials with photo + name + role

#### 3. Product Demo + Features
- **Sections**: Hero → Product video/mockup (center) → Feature breakdown → Comparison → CTA
- **CTA**: Video center + CTA right/bottom
- **Conversion**: Embedded demo increases engagement, interactive mockup preferred, auto-play muted

#### 4. Minimal Single Column
- **Sections**: Hero headline → Short description → Benefit bullets (3 max) → CTA → Footer
- **CTA**: Center, large button
- **Conversion**: Single CTA focus, large typography, lots of whitespace, mobile-first

#### 5. Funnel (3-Step Conversion)
- **Sections**: Hero → Step 1 (problem) → Step 2 (solution) → Step 3 (action) → CTA
- **Colors**: Step 1 Red/Problem → Step 2 Orange/Process → Step 3 Green/Solution
- **Conversion**: Progressive disclosure, multiple CTAs, progress indicators

#### 6. Comparison Table + CTA
- **Sections**: Hero → Problem intro → Comparison table → Pricing → CTA
- **Conversion**: 35% higher conversion, highlight your product row, include free trial

#### 7. Lead Magnet + Form
- **Sections**: Hero (benefit) → Lead magnet preview → Form (minimal fields) → CTA submit
- **Conversion**: Form fields ≤3 for best conversion, show valuable preview

#### 8. Pricing Page + CTA
- **Sections**: Hero → Price comparison cards → Feature comparison → FAQ → Final CTA
- **Conversion**: Annual discount 20-30%, recommend mid-tier (most popular badge)

#### 9. Video-First Hero
- **Sections**: Hero with video background → Features overlay → Benefits → CTA
- **Conversion**: 86% higher engagement with video, add captions, compress for perf

### Story-Driven Patterns

#### 10. Scroll-Triggered Storytelling
- **Sections**: Intro hook → Chapter 1 (problem) → Chapter 2 (journey) → Chapter 3 (solution) → CTA
- **Conversion**: 3x time-on-page, use progress indicator, simplify on mobile

#### 11. Before-After Transformation
- **Sections**: Hero (problem) → Transformation slider → How it works → Results CTA
- **Conversion**: 45% higher conversion, visual proof, specific metrics, guarantee

#### 12. Horizontal Scroll Journey
- **Sections**: Intro (vertical) → Journey (horizontal track) → Detail reveal → Footer
- **Effects**: Scroll-jacking (careful), parallax layers, progress indicator

### Specialized Patterns

#### 13. Waitlist/Coming Soon
- **Sections**: Hero with countdown → Product teaser → Email capture → Social proof
- **Conversion**: Scarcity + exclusivity, show waitlist count, referral program

#### 14. App Store Style
- **Sections**: Hero with device mockup → Screenshots carousel → Features → Reviews → Download CTAs
- **Conversion**: Real screenshots, 4.5+ star ratings, QR code for mobile

#### 15. FAQ/Documentation
- **Sections**: Hero with search bar → Popular categories → FAQ accordion → Contact CTA
- **Effects**: Search autocomplete, smooth accordion, helpful feedback buttons

#### 16. Immersive/Interactive
- **Sections**: Full-screen interactive → Guided tour → Key benefits → CTA after completion
- **Conversion**: 40% higher engagement, provide skip option, mobile fallback essential

#### 17. Event/Conference
- **Sections**: Hero (date/location/countdown) → Speakers grid → Agenda → Sponsors → Register
- **Conversion**: Early bird pricing with deadline, speaker credibility, multi-ticket discounts

#### 18. Product Reviews/Ratings
- **Sections**: Hero (product + aggregate rating) → Rating breakdown → Individual reviews → CTA
- **Conversion**: Show verified purchases, filter by rating, respond to negatives

#### 19. Community/Forum
- **Sections**: Hero (community value) → Popular topics → Active members → Join CTA
- **Conversion**: Show member count + posts today, preview content, easy onboarding

#### 20. Marketplace/Directory
- **Sections**: Hero (Search) → Categories → Featured Listings → Trust/Safety → CTA
- **CTA**: Search bar IS the CTA, reduce friction, popular search suggestions

#### 21. Newsletter/Content
- **Sections**: Hero (Value Prop + Form) → Recent Issues → Social Proof → About Author
- **Conversion**: Single field (Email only), show "Join X,000 readers", sample link

#### 22. Webinar Registration
- **Sections**: Hero (Topic + Timer + Form) → What You'll Learn → Speaker Bio → Urgency
- **Conversion**: Limited seats, "Live" indicator, auto-fill timezone

#### 23. Enterprise Gateway
- **Sections**: Hero (Video/Mission) → Solutions by Industry → By Role → Client Logos → Contact
- **CTA**: Contact Sales (primary) + Login (secondary)

#### 24. Portfolio Grid
- **Sections**: Hero (Name/Role) → Project Grid (Masonry) → About → Contact
- **Effects**: Image lazy load, hover overlay info, lightbox view

#### 25. Bento Grid Showcase
- **Sections**: Hero → Bento Grid (Key Features) → Detail Cards → Tech Specs → CTA
- **Effects**: Hover card scale (1.02), video inside cards, staggered reveal

#### 26. Interactive 3D Configurator
- **Sections**: Hero (Configurator) → Feature Highlight → Price/Specs → Purchase
- **Effects**: Real-time rendering, material swap, camera rotate/zoom

#### 27. AI-Driven Dynamic Landing
- **Sections**: Prompt/Input Hero → Generated Result Preview → How it Works → Value Prop
- **Conversion**: Immediate value demonstration, "Show don't tell", low friction start

## UI Reasoning Rules (Key Anti-Patterns)

Common mistakes to avoid by product type:

| Product Type | Anti-Patterns (NEVER DO) |
|---|---|
| Healthcare | Bright neon colors, Motion-heavy animations, AI purple/pink gradients |
| Government | Ornate design, Low contrast, Motion effects, AI purple/pink gradients |
| Finance/Banking | Playful design, Unclear fees, AI purple/pink gradients |
| Senior Care | Small text, Complex navigation, AI purple/pink gradients |
| Medical | Outdated interface, Confusing booking, AI purple/pink gradients |
| Legal | Outdated design, Hidden credentials, AI purple/pink gradients |
| Construction | 2D-only layouts, Poor image quality, AI purple/pink gradients |
| E-commerce Luxury | Vibrant Block-based, Playful colors |
| Gaming | Minimalist design, Static assets |
| Creative Agency | Corporate minimalism, Hidden portfolio |
