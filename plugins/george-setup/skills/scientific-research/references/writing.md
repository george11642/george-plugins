# Scientific Writing Reference

## Core Principles

Scientific writing communicates research with precision and clarity using IMRAD structure (Introduction, Methods, Results, And Discussion), proper citations, figures/tables, and reporting guidelines.

**Critical Rule**: Always write in full paragraphs with flowing prose. Never submit bullet points in final manuscripts. Use a two-stage process:
1. Create section outlines with key points (using literature search)
2. Convert outlines into complete paragraphs

## Manuscript Structure (IMRAD)

### Abstract
- Write as flowing paragraph(s), NOT with labeled sections (Background:, Methods:, etc.)
- 150-300 words covering: context/problem, methods, key findings with numbers, significance
- Only use structured format if journal explicitly requires it

### Introduction
- Establish research problem importance
- Review relevant literature systematically
- Identify knowledge gaps or controversies
- State clear research questions/hypotheses
- Explain study novelty and significance

### Methods
- Ensure reproducibility with detailed descriptions
- Include participant/sample descriptions, procedures, statistical methods
- Document equipment, ethical approvals, consent statements
- Use past tense

### Results
- Present findings objectively without interpretation
- Logical flow from primary to secondary outcomes
- Integrate with figures and tables
- Report statistical significance with effect sizes

### Discussion
- Relate results to research questions
- Compare with existing literature
- Acknowledge limitations honestly
- Propose mechanistic explanations and future research

## Citation Styles

| Style | Format | Common In |
|-------|--------|-----------|
| APA | (Author, Year) | Social sciences |
| AMA | Superscript numbers | Medicine |
| Vancouver | [Numbered] brackets | Biomedical |
| Chicago | Notes or author-date | Humanities/sciences |
| IEEE | [Numbered] brackets | Engineering/CS |

**Best Practices**: Cite primary sources, include recent literature (5-10 years), verify all citations against originals.

**Post-Writing Check**: Scan references.bib for entries missing volume, pages, or DOI. Search and enrich metadata before final compilation.

## Figures and Tables

- Tables for precise numerical data; figures for trends, patterns, relationships
- Make each self-explanatory with complete captions
- Label all axes with units, include sample sizes and statistical annotations
- Follow "one table/figure per 1000 words" guideline

## Writing Principles

- **Clarity**: Precise language, define terms at first use, active voice
- **Conciseness**: 15-20 word average sentences, eliminate redundancy
- **Accuracy**: Exact values, consistent terminology, distinguish observation from interpretation
- **Objectivity**: No bias, no overstating, acknowledge conflicting evidence

## Field-Specific Terminology

Match language to discipline:
- **Biomedical**: Precise clinical terminology, standardized nomenclature (ICD, MeSH)
- **Molecular biology**: Italics for genes (*TP53*), regular for proteins (p53)
- **Chemistry**: IUPAC nomenclature, proper concentration units
- **Ecology**: Binomial nomenclature, standardized habitat classifications
- **Social sciences**: Person-first language, APA bias-free guidelines

## Journal-Specific Formatting

- Follow author guidelines for structure, length, format
- Apply journal-specific citation styles
- Meet figure/table specs (resolution, file formats, dimensions)
- Include required statements (funding, conflicts, data availability, ethics)

## Workflow

1. **Planning**: Identify journal, determine reporting guideline, outline structure
2. **Drafting**: Start with figures/tables, then Methods > Results > Discussion > Introduction > Abstract
3. **Revision**: Check flow, verify terminology, ensure figures are self-explanatory, verify citations
4. **Finalization**: Format per journal, prepare supplementary materials, write cover letter

## Visual Enhancement

Every paper MUST include a graphical abstract plus additional figures. Use scientific-schematics for diagrams. Minimum figure counts: research papers (5), literature reviews (4), grants (4), presentations (1/slide).
