# Color Themes Reference

Professional color themes with exact hex codes, font pairings, psychology, and selection guidance for visualizations, presentations, slides, and dashboards.

---

## Theme Selection Flowchart

```
What industry / message are you conveying?
  ├── SaaS / AI / Tech startup     → Tech Innovation
  ├── Healthcare / Pharma / Clean  → Arctic Frost
  ├── Finance / Consulting / Corp  → Ocean Depths
  ├── Creative / Marketing / Brand → Sunset Boulevard
  ├── Environmental / Sustainability → Forest Canopy
  ├── Food / Restaurant / Artisan  → Golden Hour
  ├── Fashion / Beauty / Wedding   → Desert Rose
  ├── Garden / Natural / Organic   → Botanical Garden
  ├── Entertainment / Gaming / Luxury → Midnight Galaxy
  └── Architecture / Design / Data → Modern Minimalist

What tone?
  ├── Bold & high-contrast          → Tech Innovation or Midnight Galaxy
  ├── Warm & inviting               → Sunset Boulevard or Golden Hour
  ├── Professional & trustworthy    → Ocean Depths or Modern Minimalist
  ├── Natural & calm                → Forest Canopy or Botanical Garden
  ├── Clean & clinical              → Arctic Frost or Modern Minimalist
  └── Soft & sophisticated          → Desert Rose or Arctic Frost
```

## The 10 Themes

### 1. Ocean Depths

Professional, calming, maritime. Conveys trust and stability.

| Role | Name | Hex | RGB |
|------|------|-----|-----|
| Primary background | Deep Navy | `#1a2332` | (26, 35, 50) |
| Accent / highlights | Teal | `#2d8b8b` | (45, 139, 139) |
| Secondary accent | Seafoam | `#a8dadc` | (168, 218, 220) |
| Text / light bg | Cream | `#f1faee` | (241, 250, 238) |

**Font pairing**: Headers: DejaVu Sans Bold / Web: Inter Bold. Body: DejaVu Sans / Web: Inter.

**Psychology**: Deep navy communicates authority and reliability (used by banks and consulting firms). Teal adds approachability without sacrificing professionalism. Cream prevents harsh contrast fatigue.

**Industries**: Corporate presentations, financial reports, consulting decks, investment pitches, trust-building content.

**Dark variant**: Background `#0d1520`, text `#e8f4f8`, accent `#3ab0b0`, secondary `#5ecfcf`.

**WCAG check**: Cream `#f1faee` on Deep Navy `#1a2332` → contrast ratio ~13.5:1 (passes AAA).

## Applying Themes to Charts

### Matplotlib

```python
import matplotlib.pyplot as plt
import matplotlib as mpl

# Ocean Depths theme
OCEAN = {
    'bg': '#1a2332', 'text': '#f1faee',
    'accent1': '#2d8b8b', 'accent2': '#a8dadc',
    'grid': '#2a3a4a'
}

def apply_ocean_theme(fig, ax):
    fig.patch.set_facecolor(OCEAN['bg'])
    ax.set_facecolor(OCEAN['bg'])
    ax.tick_params(colors=OCEAN['text'])
    ax.xaxis.label.set_color(OCEAN['text'])
    ax.yaxis.label.set_color(OCEAN['text'])
    ax.title.set_color(OCEAN['text'])
    ax.spines[:].set_color(OCEAN['grid'])
    ax.grid(color=OCEAN['grid'], linewidth=0.5)
    return OCEAN['accent1']

fig, ax = plt.subplots(figsize=(10, 6))
color = apply_ocean_theme(fig, ax)
ax.bar(categories, values, color=color)
```

## Custom Theme Generation

When none of the 10 preset themes fits, generate a custom theme following this process:

1. **Identify the core emotion** the visualization should evoke.
2. **Choose a dominant hue** that maps to that emotion (blue=trust, green=growth, red=urgency, purple=luxury).
3. **Select value range**: dark background for drama/tech, light background for corporate/healthcare.
4. **Build the 4-color structure**:
   - Dark anchor (deepest value)
   - Primary accent (mid-saturation, primary action)
   - Secondary accent (lighter, supporting elements)
   - Text / background (near-white or near-black)
5. **Verify WCAG AA** (minimum 4.5:1 for body text, 3:1 for large text/graphics).
6. **Name the theme** in 2 words describing its character.

```python
def wcag_contrast(hex1: str, hex2: str) -> float:
    """Calculate WCAG contrast ratio between two hex colors."""
    def luminance(hex_color):
        r, g, b = [int(hex_color[i:i+2], 16)/255 for i in (1, 3, 5)]
        def linearize(c):
            return c/12.92 if c <= 0.03928 else ((c+0.055)/1.055)**2.4
        r, g, b = linearize(r), linearize(g), linearize(b)
        return 0.2126*r + 0.7152*g + 0.0722*b

    l1 = luminance(hex1)
    l2 = luminance(hex2)
    lighter, darker = max(l1, l2), min(l1, l2)
    return (lighter + 0.05) / (darker + 0.05)

# Usage
ratio = wcag_contrast('#f1faee', '#1a2332')
print(f"Contrast: {ratio:.1f}:1 — {'PASS' if ratio >= 4.5 else 'FAIL'} AA")
```
