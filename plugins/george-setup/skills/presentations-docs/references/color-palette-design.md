# Color Palette Design Reference

A systematic approach to selecting, building, and applying color palettes for presentations.

---

## Selection Methodology (5-Step Process)

### Step 1: Analyze Content

Before choosing any colors, answer these questions:

| Dimension | Questions | Color Implications |
|-----------|-----------|-------------------|
| **Topic** | Science/tech? Healthcare? Finance? Creative? | See curated palettes below |
| **Industry** | Startup? Corporate? Academic? NGO? | Formal vs playful; conservative vs bold |
| **Mood** | Authoritative? Energetic? Calming? Inspiring? | Cool = trust/calm; Warm = energy/action |
| **Energy** | High-stakes pitch? Academic seminar? Sales deck? | High-stakes = conservative; Sales = warm accent |
| **Audience** | Investors? Scientists? General public? Executives? | Investors: navy/gray. Scientists: minimal. Public: approachable |

### Step 2: Brainstorm Palette Angles

For any topic, generate 3 palette directions:
1. **Safe/Industry-standard** — what audiences expect
2. **Bold/Differentiated** — unexpected but on-brand
3. **Minimal/Neutral** — let content lead, not color

Example for "AI startup pitch":
- Safe: dark navy + white + blue accent
- Bold: near-black + electric cyan + white
- Minimal: white + black + single orange accent

### Step 3: Build 3-5 Base Colors

Every palette needs exactly:
- **1 Dominant** (60% of slide area): backgrounds, large shapes
- **1 Supporting** (30% of slide area): secondary backgrounds, section headers
- **1 Accent** (10% of slide area): CTAs, highlights, key data points, borders
- **1 Text** (neutral dark for body text on light backgrounds)
- **1 Background** (white, off-white, or near-black)

Never use more than 5 colors in a single presentation.

### Step 4: Test Contrast

For every text-on-background combination:
- **7:1** preferred (WCAG AAA) — all body text
- **4.5:1** minimum (WCAG AA) — large text (18pt+)
- **3:1** minimum — large bold text (24pt+ bold)

Tools: WebAIM Contrast Checker (webaim.org/resources/contrastchecker), Colour Contrast Analyser desktop app.

Test these combinations:
- [ ] Body text on primary background
- [ ] Body text on accent background
- [ ] Title text on hero image/photo backgrounds
- [ ] White text on your accent color
- [ ] Chart labels on chart background

### Step 5: Validate for Color Blindness

- Test with Coblis (online simulator) or Color Oracle (desktop app)
- Verify deuteranopia (red-green blind): most common (8% of men)
- Verify protanopia: second most common
- Verify grayscale (monochrome printing)
- If information depends on color distinction, add labels/patterns

## Color Psychology Quick Reference

| Color | Associations | Presentation Use |
|-------|-------------|-----------------|
| Navy / Dark Blue | Trust, stability, authority | Corporate, finance, government |
| Bright Blue | Innovation, intelligence, clarity | Tech, healthcare, education |
| Green | Growth, health, sustainability | Environmental, healthcare, finance (growth) |
| Teal/Cyan | Balance, calm, modern | Healthcare, data, SaaS |
| Orange | Energy, enthusiasm, warmth | Startups, creative, consumer |
| Red | Urgency, passion, warning | CTAs, alerts, sports, entertainment |
| Purple | Creativity, luxury, wisdom | Creative agencies, luxury, academia |
| Yellow/Gold | Optimism, premium, attention | Highlights, luxury accents, warnings |
| Black/Near-black | Premium, boldness, sophistication | Luxury, keynotes, dark mode |
| White/Light gray | Clarity, clean, minimal | Backgrounds, space, scientific |

## Custom Theme Generation Steps

1. **Start with one brand/topic color** — this becomes your accent
2. **Derive dominant**: darken the accent by 40-60% (HSL lightness reduction)
3. **Derive supporting**: desaturate the accent by 70% and lighten to 60-70% lightness
4. **Set background**: pure white (#FFFFFF) or warm off-white (#FAFAFA) for light mode; near-black (#121212 or #1A1A2E) for dark mode
5. **Set text**: #212121 for light mode, #F5F5F5 for dark mode
6. **Test all combinations** using the Step 4 contrast checklist above
7. **Check in grayscale** — sufficient contrast without color dependency

---

## Application Checklist

Before finalizing a palette for a presentation:

- [ ] 5 colors or fewer defined
- [ ] Dominant, supporting, accent, text, and background roles assigned
- [ ] All body text passes 4.5:1 minimum contrast
- [ ] Accent color passes 4.5:1 against white AND accent background
- [ ] Tested in deuteranopia simulation
- [ ] Tested in grayscale
- [ ] Consistent across ALL slides (no per-slide color changes)
- [ ] Accent used sparingly (only 10% of visual area)

## Hex to python-pptx RGBColor

```python
from pptx.dml.color import RGBColor

# Convert hex string to RGBColor
def hex_to_rgb(hex_str):
    hex_str = hex_str.lstrip('#')
    r, g, b = int(hex_str[0:2], 16), int(hex_str[2:4], 16), int(hex_str[4:6], 16)
    return RGBColor(r, g, b)

# Example
ACCENT = hex_to_rgb('#FF6B35')
shape.fill.fore_color.rgb = ACCENT
```

## Theme Application in python-pptx

```python
def apply_theme(slide, palette):
    """Apply consistent palette to a slide's background and text elements."""
    # Background
    background = slide.background
    fill = background.fill
    fill.solid()
    fill.fore_color.rgb = hex_to_rgb(palette['background'])

    # Title text
    for shape in slide.shapes:
        if shape.has_text_frame:
            for para in shape.text_frame.paragraphs:
                for run in para.runs:
                    run.font.color.rgb = hex_to_rgb(palette['text'])

# Usage with palette #10 (Minimal/Clean)
MINIMAL_PALETTE = {
    'dominant': '#FFFFFF',
    'supporting': '#F5F5F5',
    'accent': '#1565C0',
    'text': '#212121',
    'background': '#FFFFFF'
}
apply_theme(slide, MINIMAL_PALETTE)
```
